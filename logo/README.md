# @docbeyondthebarbell — logo

The symbol is a barbell whose bar carries one heartbeat: medicine and lifting in one line.
All text is converted to outlines, so the SVGs need no fonts installed.

| File | Use |
|------|-----|
| `profile-picture` | Instagram / WhatsApp profile photo (1080 × 1080, safe inside the circle crop) |
| `badge-dark` | Story highlights, merch, stickers |
| `badge-gold-transparent`, `badge-white-transparent` | Watermark on reels and photos |
| `horizontal-dark` / `-light` / `-white-transparent` | Website header, YouTube banner, video lower-thirds |
| `stacked-dark` / `-light` | Posters, T-shirts, intro slides |
| `mark-gold-transparent`, `mark-black-transparent` | Symbol on its own (favicon, small spaces) |

Colours: gold `#c8963e`, black `#0e0d0c`, off-white `#ece6da`, cream `#ebe4d6`, rust `#a8402b`.
Fonts in the wordmark: Anton (headline), Inter Bold (small text).

`svg/` holds the editable vectors (open in Illustrator, Figma, Canva or Photoshop). `png/` holds 2× renders,
transparent where the file name says so. Rebuild with `python3 build_logo.py && node render.js`.
